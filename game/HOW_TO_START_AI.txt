====================================================
  HOW TO START THE AI MODEL (Qwen 3.5-9B)
====================================================

Your GGUF file is at:
  C:\Users\Rogheye\Qwen3.5-9B.Q5_K_M.gguf

----------------------------------------------------
OPTION A — LM Studio (EASIEST, no coding needed)
----------------------------------------------------
1. Download LM Studio from https://lmstudio.ai
2. Open LM Studio
3. Click "My Models" → "Load Model from File"
4. Select C:\Users\Rogheye\Qwen3.5-9B.Q5_K_M.gguf
5. Go to "Local Server" tab (left sidebar)
6. Set port to 1234 (default)
7. Click "Start Server"
8. Run the game — AI will auto-connect on port 1234

----------------------------------------------------
OPTION B — llama-cpp-python (command line)
----------------------------------------------------
1. Double-click start_server.bat  (in this folder)
   It installs llama-cpp-python if needed, then
   starts the server on http://localhost:8000

   OR manually:
   pip install "llama-cpp-python[server]"
   python -m llama_cpp.server \
     --model "C:\Users\Rogheye\Qwen3.5-9B.Q5_K_M.gguf" \
     --port 8000 --n_ctx 2048 --chat_format chatml

2. Run the game in a SEPARATE terminal:
   python main.py

----------------------------------------------------
OPTION C — Ollama
----------------------------------------------------
1. Install Ollama from https://ollama.ai
2. Import your GGUF:
   ollama create qwen35 -f Modelfile
   (Create a Modelfile with: FROM C:\Users\Rogheye\Qwen3.5-9B.Q5_K_M.gguf)
3. ollama serve   (starts on port 11434)
4. python main.py

====================================================
  The game runs fine WITHOUT AI — it uses built-in
  fallback bosses and fixed difficulty. AI adds
  dynamic scaling and unique content.
====================================================
